# Online Exam System V2

## Next.js + Vercel + Firebase

### Final Technology Stack

| Component      | Technology                           | Purpose                                                 |
| -------------- | ------------------------------------ | ------------------------------------------------------- |
| Frontend       | Next.js + React + TypeScript         | Entire web application                                  |
| Hosting        | Vercel                               | Deploy frontend                                         |
| Authentication | Firebase Authentication              | Teacher login + temporary student authentication        |
| Database       | Cloud Firestore                      | Students, exams, questions, attempts, results           |
| Backend        | Firebase Cloud Functions             | Verification, grading, violations, sensitive operations |
| Security       | Firestore Security Rules + App Check | Protect data                                            |
| Export         | SheetJS (`xlsx`)                     | XLSX/CSV export                                         |
| State          | React Context or Zustand             | Exam/session state                                      |
| Repository     | GitHub                               | Source control + Vercel deployment                      |

# PHASE 12 — SERVER-AUTHORITATIVE TIMING

This is important.

The browser timer is only the visual timer.

The server determines:

```text
Exam opening time
Exam closing time
Attempt start
Attempt submission
```

Therefore students cannot legitimately extend the exam simply by manipulating:

```text
setInterval()
Date.now()
```

or browser JavaScript.

# PHASE 22 — OFFLINE / NETWORK FAILURE

Use Firestore offline persistence carefully.

Normal answer flow:

```text
Student answers
       ↓
Local Firestore cache
       ↓
Firestore
```

If Internet temporarily drops:

```text
Student continues
       ↓
Answers stored locally
       ↓
Connection returns
       ↓
Synchronization
```

But the server remains authoritative for:

```text
deadline
submission
grading
attempt status
```

This prevents offline persistence from accidentally becoming a way to extend exam time.
